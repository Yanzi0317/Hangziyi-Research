# 问卷研究资料接入

已增加真实汇总文本导入器与审核后研究上下文接口；没有创建新人物、问卷回答或 Beta 数据。原始汇总只保存在 gitignored 的 work/research/ 隔离目录，不包含于提交、生产构建或模型请求。

## 状态

本次数据存在参与同意范围与跳题分母待核实问题，未启用。默认版本仍为 v3，v1–v4 的历史提示词保持不变。新增 v3.1 作为问卷接入候选；没有获批数据文件时在模型调用前失败，不静默伪装为已采用问卷。

## 导入

`pnpm import:survey <本地汇总文本路径>`

解析单选、多选、矩阵与量表，保留原始计数和报告百分比，校验题目ID、分母、四舍五入与量表均值。输出 aggregate.json 与 audit.md，仅用于本地核对。可重复导入相同文件，不覆盖已修改数据。

审核必须核实同意范围，必要时由数据维护者重新导出仅含同意者的汇总；不能从边际分布机械删除人数。跳题问题可独立排除，但不能绕过整体同意问题。未知调查日期、招募方法和抽样范围保留未知。

## 获批后的用途（尚未激活）

| 题目 | 可以支持的产品用途 | 不支持的推断 |
| --- | --- | --- |
| Q1–Q10 | 说明样本覆盖及适用限制 | 按背景给个人评分；推断分组关联 |
| Q11–Q15、Q18、Q23 | 自报使用方式、资源和实践约束的群体描述 | 用总体频率判断个人能力或AI工具开发水平 |
| Q16–Q17、Q21、Q28 | 提示任务变化、未确定性与需要核实的问题 | 当前招聘需求、因果性裁员预测 |
| Q19–Q20 | 区分主观预期与客观证据 | 个体概率或平台NPS职业评分 |
| Q22 | 帮助决定解释与操作信息的展示优先级 | 人格或职业匹配推断 |
| Q25 | 跳题口径修正后才考虑使用 | 在分母不明时估计效率或工作量变化 |
| Q26–Q27、Q29 | 分开解释技能重要性、自评与资源态度 | 把信心等同技能；把态度当因果事实 |
| Q30 | 当前未提供开放题内容 | 编造原话或主题 |

数据审核通过且用户确认使用后，维护者才能创建 data/research/approved/<datasetId>.json，满足 approvedSurveySchema。获批文件包含精简发现及来源题目、分母、局限，不包含个体数据。是否发布这些研究汇总须另行明确，不把本地导入等同于公共发布。

模型请求与结果元数据记录研究快照及哈希；问卷不混入市场信号。不能将这份小样本汇总称为经过校准的预测模型。
