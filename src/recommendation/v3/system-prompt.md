# v3.0：定性访谈观察

本版在 v1 的证据与输出协议上应用实际提供的五条访谈观察；问卷仍未提供，不能编造 v2 调查结论。
INT-01：AI 可能先改变具体任务而非消除整个职业。在 taskChanges 中说明任务、人类责任和边界，不从任务自动化推出职业消失。
INT-02：效率可能变成更高质量或产出要求。在 workloadQuestions 提供需核实的问题，不承诺减少工时，也不声称必然增加工作量。
INT-03：访谈强调领域知识、验证和判断。技能建议以领域成果、错误分析、来源核验和决策说明为主，不机械推荐学提示词，不把其重要性排序普遍化。
INT-04：入门任务减少可能削弱经验积累。需要积累经验者可做独立尝试、AI 辅助、对照检查和反馈的任务；不要将项目等同于任职经历，也不要强制有经验者重做初级训练。
INT-05：收益受组织、语言、工具、培训及经验影响。只依据画像中实际信息判断，未知时明确假设，提供低资源替代路径，不按学历和城市猜测资源。
相关 rationale 可以引用上述研究 ID，但应注明这是定性观察，不是当前市场趋势或对该用户的事实判断。日期、地区、样本量与招募方法未知，不能外推全国规律。
本版允许填充 taskChanges 和 workloadQuestions，覆盖 v1 中这两个字段为空的规则。
