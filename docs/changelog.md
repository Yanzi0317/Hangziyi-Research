# Changelog

## v3.2 真实研究支持的条件性情景预测

- 接入49份获批问卷精选汇总与六人访谈匿名主题，保留来源、题号、分母与资料指纹。
- 按提供者对同意记录的明确更正使用原始49人分母，不缩放；Q25仍排除。
- 增加无需模型密钥的条件预测、用户确认任务/资源/学习阶段，以及反向情景与验证步骤。
- 默认v3.2；同一证据接入LLM建议和证据面板，旧版本及隔离原件保持不变。
- 不把描述性比例转成个人就业概率，不训练虚假统计模型、不生成Beta数据。

## 问卷汇总导入与审核入口

- 增加单选、多选、矩阵和量表导入、计数及百分比核对。
- 原始汇总只存本地隔离目录，未批准发布或用于推荐。
- 新增 v3.1 研究上下文入口；缺少获批问卷时在模型调用前阻止运行。
- 保留 v1–v4 原提示词与默认 v3；不把边际分布转成个人预测或跨群体关联。

## 应用实现 · 排除 Beta 调研

- 从空骨架实现 Next.js 页面、画像校验、服务端模型调用、推荐/技能行动与证据展示。
- 注册 v1/v2/v3/v4，默认 v3；v2 明示调查缺失，v4 为待验证草案。
- 接入人工聚合快照和内存缓存；实时搜索供应商未配置。
- 建立十份合成软件测试画像、/compare 和回归 CLI；不将其视为真实调研。
- 不创建 Beta 参与者记录、反馈保存或研究数据导出。
- 完成 mock 测试与生产构建；没有模型凭据，未生成真实推荐基线。

## Beta 测试：真人参与、逐版本记录、隐私保护

- 新增 /consent 中英文同意页；不同意仍可试用，但不保存任何内容、不能提交反馈。
- 同意后每次生成在服务端记录：匿名参与者编号、逻辑版本与提示词哈希、去标识画像副本、结果全文、情景条件。v1–v4 及 v3.1/v3.2 全部可测。
- /feedback 恢复为五个固定问题（最有用、最不合理、忽略背景、是否相信及原因、只改一处），按生成记录关联。
- 保存前自动删除邮箱、电话、证件号、链接、社交账号、自我介绍姓名和机构名称；仍含联系方式则拒绝保存。不记录 IP、UA、Cookie。
- 存储可插拔：默认本地 JSONL（data/beta-records，git 忽略）；可选 HTTPS webhook 转发用于无盘托管。
- 新增 `pnpm export:beta`（匿名 CSV/JSON，按版本汇总）、`pnpm withdraw:beta <编号>`（凭参与者编号删除）、`pnpm mock:llm`（本地假模型，仅用于流程演练）。
- 邀请链接支持 `/consent?v=v2&k=<访问密钥>&c=<分组>` 预选版本、填入密钥、标注分组。
- 撤销 v4 提示词与页面中“Beta 已取消”的说法；合成画像回归工具保留但移到导航末尾，仅供开发。
