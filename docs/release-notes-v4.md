# v4 实现状态

v4.0-draft.1 已注册为可运行提示词版本；默认版本仍是 v3。共享引擎与结构化协议已实现，未配置模型时明确报错。

用户已取消 Beta 调研。本次没有参与者记录、研究反馈采集、研究导出或虚构调研结果。此前“禁止所有合成人物”的扩大解释已撤销：十份合成画像仅用于软件回归。

## v3 → v4 的设计差异

v3 使用五条定性访谈观察；v4 在这些观察上进一步要求：解释什么证据会改变建议、避免机械延续既往行业、把资源未知作为假设、以实际成果验证技能。它不是 Beta 反馈驱动的升级。

五条观察分别涉及任务变化、工作量预期、领域与验证能力、入门经验路径和资源差异。未知日期、地区、样本与方法仍然明确标注。

## 实际验证

版本注册、十份软件测试画像、输出 schema、引用约束、评分清理与差异计算已做 mock 测试。网页与生产构建可运行。

尚无真实模型调用输出。tests/outputs/v1、v2、v3、v4 中不生成虚假的成功结果。因此不能提供逐画像前后引文、判断哪些画像改善最多或声称 v4 优于 v3。配置模型后由 CLI 产生真实基线再比较。
