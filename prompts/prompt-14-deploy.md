- 在现有 src/recommendation/registry.ts 将默认版本设为 v3，保留 v1/v2 的独立实现；未知版本明确报错。禁止改写历史版本逻辑。

- README 覆盖实际可运行的设置命令、变量、添加版本、CLI 回归、Vercel 部署、访问保护和 Beta 验收。
